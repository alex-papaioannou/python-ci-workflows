# Upgrading

Breaking changes ship only in a new major version, so a caller pinned to a major tag
such as `@v1` never receives one. Before moving to the next major tag, work through
the entries for it below.

Each entry is a `###` heading under the section for its major version. It says what
changed and which callers it affects, and shows the calling workflow before and
after. The entry's bullet under Breaking changes in [CHANGELOG.md](CHANGELOG.md)
links to it. Entries for v2 are added here as its breaking changes merge, before
v2.0.0 is released.
